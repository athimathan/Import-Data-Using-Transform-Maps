## Documented workflow
1. Prepare employee data in Google Sheets / Excel.
2. Create the `Employee Test` custom table (`u_employee_test`).
3. Create the `Employee Import` Import Set table (`u_employee_import`).
4. Create the `Sample Spreadsheet Import` Transform Map.
5. Map Employee ID, Employee Name, Email, Department and Location.
6. Enable Coalesce on Employee ID.
7. Run Transform and validate the results.
8. Create Employees by Department, Employees by Location and Employee List Report.
9. Add the reports to `Employee Analytics Dashboards`.
